# Contributing to GeckoCIRCUITS

Thank you for your interest in contributing!

For the full contributing guide, including development setup, code architecture, and PR process, see our **[Contributing Guide](https://tinix84.github.io/GeckoCIRCUITS/resources/contributing/)**.

## Quick Start

```bash
git clone https://github.com/tinix84/GeckoCIRCUITS.git
cd GeckoCIRCUITS
mvn clean package assembly:single -DskipTests
mvn test
```

## Questions?

Open a [GitHub Issue](https://github.com/tinix84/GeckoCIRCUITS/issues) or [Discussion](https://github.com/tinix84/GeckoCIRCUITS/discussions).
