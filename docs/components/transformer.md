# Ideal transformer

An ideal transformer relates primary and secondary voltage and current by the turns ratio.

## Terminals

Two primary and two secondary electrical terminals.

## Parameters

| Parameter | Unit | Function |
| --- | --- | --- |
| Primary and secondary turns | — | Set the winding turns ratio. |
| Winding orientation | — | Sets the relative winding polarity. |

## Model

The ideal model represents the turns ratio.
