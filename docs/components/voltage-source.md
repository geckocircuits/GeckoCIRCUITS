# Voltage source

A voltage source sets the voltage between its terminals.

## Terminals

Two electrical terminals. The source voltage is positive at the first terminal relative to the second.

## Parameters

| Parameter | Unit | Function |
| --- | --- | --- |
| Source type | — | Selects the waveform or control mode. |
| DC value | V | Sets the voltage in DC mode. |
| Amplitude and offset | V | Set the waveform level for applicable source types. |
| Frequency and phase | Hz and ° | Set the timing for periodic waveforms. |

## Model

The selected source type determines which fields apply.
