# Diode

A diode conducts from anode to cathode when the forward condition is met.

## Terminals

Anode and cathode.

## Parameters

| Parameter | Unit | Function |
| --- | --- | --- |
| On and off resistance | Ω | Set the resistance in each conduction state. |
| Forward voltage drop | V | Sets the drop used in the linear on-state model. |
| Nonlinear characteristic | — | Enables the configured forward characteristic. |

## Model

The solver updates the conduction state as the circuit runs.
