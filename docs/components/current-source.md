# Current source

A current source sets the current through its branch.

## Terminals

Two electrical terminals.

## Parameters

| Parameter | Unit | Function |
| --- | --- | --- |
| Source type | — | Selects the waveform or control mode. |
| DC value | A | Sets the current in DC mode. |
| Amplitude and offset | A | Set the waveform level for applicable source types. |
| Frequency and phase | Hz and ° | Set the timing for periodic waveforms. |

## Model

The selected source type determines which fields apply.
