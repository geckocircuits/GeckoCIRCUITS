# MOSFET

The metal-oxide-semiconductor field-effect transistor switches current in a power branch.

## Terminals

Drain and source. A gate control block supplies the command.

## Parameters

| Parameter | Unit | Function |
| --- | --- | --- |
| On and off resistance | Ω | Set the switch resistance in each state. |
| Antiparallel diode on and off resistance | Ω | Set the diode resistance in each state. |
| Antiparallel diode forward drop | V | Sets the forward voltage drop of the diode model. |

## Model

The model uses controlled switch behavior and an antiparallel diode model.
