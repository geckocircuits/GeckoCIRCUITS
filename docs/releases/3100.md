# v3.1.0 Release Notes — REST API Hardening

**Release Date**: November 2026

v3.1.0 hardens the REST API for shared use: pagination, rate limits, JWT, roles and generated client SDKs. It also makes the GUI-free core the default engine behind the desktop. Results on the 21 education circuits match the v2.02 Golden references within 1%.

## REST API

- **Pagination** for circuit and simulation lists, with `page`, `size` (default 20, max 100) and `sort` (#96)
- **Rate limits** per client for requests and simulations: `gecko.api.rate-limit`, `gecko.api.rate-limit-simulation` (#97)
- **JWT** access and refresh tokens, off by default: `gecko.api.jwt.enabled` (#99)
- **Roles** (ADMIN, USER, READONLY) per API key: `gecko.api.roles.<keyId>` (#100)
- **WebSocket topics** are authorized by owner, so a client sees only its own simulations (#98)
- **Generated SDKs** for Python, Java and TypeScript, built from the live OpenAPI contract (`scripts/generate-sdks.sh`) (#103)
- Status and single-signal reads no longer copy every waveform (#84)
- STOMP progress is sent as a percentage (#85)

## Simulation engine

- The desktop runs simulations through the GUI-free core by default. Choose the engine with `-Dgecko.backend=core|legacy|auto` (#86, #87)
- Circuit preparation checks readiness before a run, and CONTROL blocks execute in dependency order (#81)
- Fixes:
  - CONTROL-to-electrical coupling (#80)
  - shared CONTROL delay history (#83)
  - analysis windows and recorded clocks (#82)
  - circuits with electrically isolated groups (#91)
  - Simulink external stepping past the configured end (#90)
- The parser keeps saved data across the whole circuit corpus (#101)

## Desktop

- Zoom schematics with Ctrl + mouse wheel (#94)
- The feedback dialog links to GitHub Issues (#93)
- Dialog icons load correctly inside packaged JARs (#92)

## Upgrade notes

- **List endpoints are paginated.** A client that expects every item in one response must now request successive pages.
- **API keys without a configured role keep ADMIN** (`gecko.api.default-role=ADMIN`), for compatibility. Set `gecko.api.roles.<keyId>` to restrict existing keys.
- **STOMP progress is now 0–100.** SSE progress is still a 0–1 ratio.
